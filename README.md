# DOI 清单顺序

一个适用于 **Zotero 9.0.x** 的插件，用于按参考文献清单排列文献，并支持在文献列表中手动拖拽调整顺序。

## 用途

整理论文参考文献时，文献在 Zotero 中的排列往往与原稿清单不一致。本插件通过独立的“参考文献序号”列，帮助用户保留清单编号、恢复已有文献顺序，并按需要手动调整位置。

主要功能：

- **按清单排序**：使用魔杖导入 DOI 时，记录输入顺序；支持带原编号的参考文献清单。
- **恢复已有文献顺序**：从剪贴板读取完整清单，对已有条目匹配编号，无需重新导入。
- **保留缺失位置**：部分文献未导入时保留原编号空位，避免后续条目编号前移。
- **支持无 DOI 文献**：通过正式链接或完整标题匹配条目。
- **补齐缺少的文献**：只尝试导入尚未匹配的条目。
- **手动拖拽排序**：在 Zotero 中间文献列表内上下拖动，支持多选移动，并在本机保存顺序。
- **恢复原清单编号**：手动排序与原清单分别保存，可切换回原清单顺序。

## 安装与使用

1. 从本项目 **Releases** 下载 `.xpi` 安装包。
2. 在 Zotero 中打开 **工具 → 插件**，选择 **从文件安装插件**。
3. 安装后重启 Zotero。
4. 如需手动排序，选中文献分类，点击 **工具 → DOI 清单顺序 → 启用手动拖拽排序**。

拖动到目标行的上半部可插入其前方，下半部可插入其后方。操作前请清除搜索和标签筛选。

## 使用范围

- 目前仅声明支持 **Zotero 9.0.x**。
- 排序数据保存在本机，不随 Zotero 文库同步。
- 插件不修改标题、作者、标签等文献字段。
- **文库列表顺序与 Word 引用编号相互独立**，拖拽不会改变 Word 中的参考文献排列。
- 当前采用手动下载安装包更新，尚未配置自动更新服务。
